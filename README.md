## 🚀 Что умеет:
- Добавление и удаление задач.
- Редактирование текста задачи (правый клик).
- Закрепление важных задач (они становятся желтыми и поднимаются наверх).
- Автосохранение в файл `tasks.json` (задачи не пропадают после закрытия).
- Кнопка "Сохранить как..." для экспорта задач в другую папку.

## 🛠️ Технологии:
- Python 3
- CustomTkinter 
- JSON 

## 💻 Как запустить:
1. Установите библиотеку: 
   `pip install customtkinter`
2. Запустите файл: 
   `python todo.py`

На этом все :)
