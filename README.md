# note 📝

This is my first program :) I don't know, people, it's just a reminder. I don't know why I made it, but I created this masterpiece in 1 hour.
I built it on my knees. I don't know, maybe someone will like it and someone needs it (which I doubt) XD

## 🚀 What it does:
- Add and delete tasks.
- Edit task text (right-click).
- Pin important tasks (they turn yellow and move to the top).
- Autosave to `tasks.json` file (tasks don't disappear after closing).
- "Save as..." button to export tasks to another folder.

## 🛠️ Technologies:
- Python 3
- CustomTkinter 
- JSON 

## 💻 How to run:
1. Install the library: 
   `pip install customtkinter`
2. Run the file: 
   `python todo.py`

That's it :)
